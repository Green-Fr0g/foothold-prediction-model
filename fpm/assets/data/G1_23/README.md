# G1_23 资产核对说明

入口文件为 `g1_23dof_rev_1_0.usd`，场景以米为单位，Z 轴朝上。默认图元为 `/g1_23dof_rev_1_0`，浮动关节系统的根节点为 `/g1_23dof_rev_1_0/pelvis`。三个配置 USD 图层均可通过本地路径解析。

材质引用了 `OmniPBR.mdl`，该材质由 Isaac Sim 的 MDL 搜索路径提供；独立运行 OpenUSD 时无法解析这一渲染材质。

## 资产结构

资产包含 23 个转动关节、24 个刚体和 32 个碰撞形状，每只脚各有 4 个碰撞球。碰撞形状位于实例代理内部。

| 分组 | 关节名称后缀（除特别说明外，均包含左右两侧） | 数量 |
| --- | --- | --- |
| 腿部 | `hip_pitch_joint`、`hip_roll_joint`、`hip_yaw_joint`、`knee_joint` | 8 |
| 踝部 | `ankle_pitch_joint`、`ankle_roll_joint` | 4 |
| 腰部 | 仅 `waist_yaw_joint` | 1 |
| 手臂 | `shoulder_pitch_joint`、`shoulder_roll_joint`、`shoulder_yaw_joint`、`elbow_joint`、`wrist_roll_joint` | 10 |

资产不包含腰部 pitch/roll 关节，也不包含腕部 pitch/yaw 关节。现有环境使用的 `pelvis`、`torso_link`、`left_ankle_roll_link` 和 `right_ankle_roll_link` 均存在。腕部刚体名称为 `left_wrist_roll_rubber_hand` 和 `right_wrist_roll_rubber_hand`。

`fpm/assets/__init__.py` 中的 `G1_23_CFG` 使用隐式位置执行器。PD 增益与转子惯量参考 `mjlab/src/mjlab/asset_zoo/robots/unitree_g1/g1_constants.py`：

- 髋部 pitch/yaw 和腰部 yaw 使用 7520-14 电机参数。
- 髋部 roll 和膝关节使用 7520-22 电机参数。
- 手臂使用 5020 电机参数。
- 踝关节使用两倍的 5020 增益与转子惯量。

踝关节保留此 USD 版本的 `35 N·m` 力矩上限和 `30 rad/s` 速度上限；29 自由度配置对应的上限为 `50 N·m` 和 `37 rad/s`。其余关节的力矩、速度上限与两套配置均一致。

## 初始姿态与验证情况

初始姿态参考 mjlab 的 `KNEES_BENT_KEYFRAME`：根节点高度为 `0.76 m`，髋部 pitch 为 `-0.312 rad`，膝关节为 `0.669 rad`，踝部 pitch 为 `-0.363 rad`，肘关节为 `0.6 rad`，肩部 pitch 为 `0.2 rad`，左右肩部 roll 分别为 `+0.2 rad` 和 `-0.2 rad`。其余关节位置以及全部关节速度均初始化为零。

所有初始关节位置均位于硬限位和软限位内。根据 USD 关节坐标系进行正向运动学计算后，最低的脚部碰撞球距 `z=0` 平面约 `3 mm`。

资产已通过独立 OpenUSD 检查，尚未进行 Isaac Sim 动力学、接触行为与训练验证。`env_cfg.py` 中的 `FPM-G1-23-*` 任务使用该资产，对称增强根据实际关节名称生成映射。训练、播放和验证脚本默认使用 G1_23，训练日志独立保存在 `logs/rsl_rl/g1_23_fpm/`。
